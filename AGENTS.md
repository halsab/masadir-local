# Masādir Desktop

## Project

- Локальное desktop-приложение для полнотекстового поиска по библиотеке книг.
- Electron + TypeScript + HTML/CSS.
- Обязательные платформы MVP: macOS 13+ Apple Silicon arm64 и Windows 10/11 x64.
- Recoll CLI — локальное поисковое ядро.
- Backend, cloud search и telemetry отсутствуют.

## Source of truth

- Сначала прочитать `docs/README.md`.
- Для текущей задачи читать только относящиеся к ней канонические документы.
- Текущий stage prompt задаёт точный scope реализации.
- Google Drive-документы из `docs/README.md` — канонические проектные решения.
- Если Drive недоступен, не блокировать задачу, когда stage prompt уже содержит нужный контракт.
- Не проводить повторный архитектурный анализ без конкретного конфликта.

## Engineering

- Минимальное корректное решение вместо универсальной архитектуры «на будущее».
- Не делать несвязанный refactor.
- Не добавлять зависимости, абстракции, слои или тесты без текущей необходимости.
- Не менять решения предыдущих этапов без блокирующей технической причины.
- Renderer не получает Node.js/Electron privileges.
- Не добавлять React/Vue, backend, telemetry, auto-update, realtime watcher, OCR, собственный search engine.
- Пользовательские данные и книжный текст считать недоверенными.
- Секреты и credentials никогда не коммитить.

## Testing

- Запускать только тесты изменённого модуля и прямых контрактов.
- Полный suite не является ритуалом после каждой правки.
- Не писать snapshot/e2e/UI-тесты без явной необходимости текущего этапа.

## Git

- `git status` перед изменениями.
- Не трогать чужие незакоммиченные изменения.
- Внутри этапа делать несколько логических промежуточных коммитов.
- После завершения этапа — отдельный `complete stage X` commit.
- Push/force-push/PR/release/change remote запрещены: пользователь делает push сам.
- Не amend/rebase/reset --hard без необходимости.

## Skills/plugins

- Не каталогизировать все skills перед задачей.
- Использовать уже доступный специализированный skill только если он прямо полезен текущей работе.
- Не устанавливать новые skills/plugins автоматически.
- Provider-specific Electron skills не применять к Masādir.
- Broad planning/TDD workflows не подключать: проектирование уже выполнено.
